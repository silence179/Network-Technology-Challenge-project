# 实验0：现实差距验证

## 文档状态（2026-05）

Experiment 0 仍保持原始设计，不接入 `nocache/lce_lru/greedy/madrl/submod/spacecache/myopic/otcp` 这 8 个新增内容/缓存 baseline。

原因是本实验验证的是**建模深度差异**（A/B/C 三种物理与拥塞认知层次），而不是“多算法同场景横评”。因此它和当前已经集成 11 方法的 Experiment 1/2/3 属于不同维度的验证脚本。

## 目标

证明在相同的真实卫星-UAV轨迹上应用不同的**建模深度**会导致显著不同的路由决策和网络性能。这是“现实差距”论点：忽略关键物理效应的模拟器将产生与更真实模型不同的决策，并与真实网络的体验产生偏差。

## 实验设计

| 维度 | 设置 |
|------|------|
| 场景 | SAT-25星座（118颗卫星）+ 10架UAV + 1个地面站 |
| 轨迹 | 真实轨道力学（ECEF坐标，600秒时间线） |
| 步骤 | 50步，均匀采样整个600秒窗口 |
| 流量 | UAV_01–UAV_05 → GS_01（5个并发上行流量） |
| 指标 | **平均体验路径时延**（ms）和**路径重构次数** |

比较三种模式。**仅模型深度不同**；轨迹对三种模式完全相同：

| 模式 | LoS过滤 | 路由权重 | 拥塞感知 |
|------|---------|----------|----------|
| **Baseline-A** | 禁用 | 跳数 (=1) | 无 |
| **Baseline-B** | ≥ 30°仰角 | 传播时延 | 无 |
| **Ours (C)** | ≥ 30°仰角 | 时延 + 拥塞估计 | ✓ 基础负载模型 |

### 拥塞模型

每条链路分配一个稳定的**基础利用率**ρ（根据链路类型从Beta分布中抽取）：

| 链路类型 | 平均ρ | 备注 |
|----------|-------|------|
| UAV–SAT  | ~0.61 | 高需求，20 Mbps信道 |
| SAT–GS   | ~0.34 | 中等需求 |
| SAT–SAT  | ~0.17 | 骨干网，低竞争 |

每跳体验时延 = 传播时延 × (1 / (1 − ρ)) —— M/M/1排队减速因子。

模式C估计基础负载（±5%噪声），并在路由权重中添加常数惩罚项`(ρ_est − 1) × 5 ms`，以避开持续负载较高的上行链路。

## 结果

```
==========================================================================
  现实差距验证  (50步 × 5 UAV→GS_01流量)
==========================================================================
  方法                  平均时延 (ms)   重构次数   每步链路数
--------------------------------------------------------------------------
  Baseline-A (跳数)         8.28           55         514
  Baseline-B (仅时延)       8.12           55         484
  Ours      (完整模型)      5.38           70         484
==========================================================================
```

### 关键观察

1. **时延 (A > B > C)**：跳数模型（A）通过NetworkX解析的第一个卫星路由——通常是高负载链路——导致平均体验时延为8.28 ms。添加传播时延感知（B）略微改善至8.12 ms。完全拥塞感知路由（C）通过持续绕过饱和的上行链路，将时延减少了**34%**（5.38 ms）。

2. **重构次数 (C > A = B)**：模式A和B仅在卫星进入或离开覆盖范围（纯拓扑事件）时触发路径变化，各触发55次重构。模式C更具*主动性*：每当其拥塞估计表明有更好的替代路径时，它都会调整路径，导致70次重构（比B多27%）。关键是，每次这样的调整都带来了更低时延的路径——额外的开销因质量提升而得到正当化。

3. **链路多样性 (A > B = C)**：模式A每步构建514条链路（无LoS过滤），而B和C应用30°仰角阈值，仅保留484条高质量链路。模式A的额外低仰角链路提供了更多跳数选项，但几何质量较差——这是现实差距的另一个维度。

### 结论

> 使用**相同的真实卫星-UAV轨迹**，三种模型做出了可测量的不同路由决策。浅层模型（A）完全忽略链路质量，导致最高时延。添加传播时延感知（B）提供了适度改进。完整模型（C）——包括LoS几何和拥塞估计——实现了比B**34%的时延减少**，直接验证了模拟精度对路由质量的显著影响，并强调了在卫星-UAV系统中进行准确网络建模的必要性。
