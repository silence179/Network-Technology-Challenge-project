# ACS-SCOS 空天地一体化网络真实时空驱动仿真与协同优化系统

## 环境要求

- [Node.js](https://nodejs.org/) >= 18
- [Python](https://www.python.org/) >= 3.8
- [Git](https://git-scm.com/)

Python 依赖（按需安装）：

```bash
pip install numpy pandas pymap3d skyfield scipy networkx
```

---

## 启动 Web 前端

### Windows

双击项目根目录下的 `start-vis.bat`，或在命令行中执行：

```bash
start-vis.bat
```

### Linux / macOS

```bash
chmod +x start-vis.sh
./start-vis.sh
```

启动后浏览器自动打开主页面。

---

## Web 前端界面说明

前端共三个页面：**主页面** → **仿真地球** + **数据导入**。

---

### 1. 主页面（Landing Page）

访问 `http://localhost:5173` 进入，包含两个功能入口：

| 按钮 | 跳转 | 说明 |
|------|------|------|
| **进入系统** | 仿真地球页面 | 3D Cesium 地球 + 实时拓扑/性能面板 |
| **轨迹导入** | 数据导入页面 | 管理所有数据文件，支持手动导入和程序生成 |

---

### 2. 仿真地球页面

URL：`/earth.html`

- **3D 地球视图**：Cesium 渲染卫星（🛰️）、地面站（📡）、无人机（🚁）的实时轨迹与模型
- **视角切换**：顶部导航栏下拉框可选择全局概览或追踪特定节点
- **网络拓扑面板**：点击「网络拓扑」按钮，右下角弹出 ECharts 二维力导向图，展示当前时刻各节点间的链路状态
- **网络性能面板**：点击「网络性能」按钮，左下角弹出性能折线图，展示时延、吞吐量等指标
- 两个面板均可**拖拽移动**
- 左上角「← 返回主页」可回到主页面

---

### 3. 数据导入页面

URL：`/import.html`

页面包含 4 个数据管理区域，每个区域**同时支持手动导入和程序生成**。

---

#### 🛰️ 卫星轨迹导入

| 功能 | 操作 |
|------|------|
| **手动导入** | 拖拽或点击选择 `sat_trace_*.csv` 文件，自动保存到 `public/data/sat_trace/` |
| **打开文件夹** | 点击「打开文件夹」在资源管理器中定位目标目录 |
| **程序生成** | 点击「程序生成」→ 弹出参数配置窗口 → 点击「开始生成」→ 后台运行 S1 模块 |

**S1 可配置参数：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 仿真时长 | 600 秒 | 轨迹总时长 |
| 观测点纬度/经度/海拔 | 30.0 / 104.0 / 459 | 救援中心坐标 |
| 动态重选卫星数 | 40 | 每轮可见卫星数 |
| 最小仰角 | 0° | 可见性筛选阈值 |
| 最大距离 | 2000 km | 距离筛选阈值 |
| 切片时长 | 60 秒 | CSV 分片粒度 |

> S1 输出：`S3/traces/sat_trace_{N}/` + `vis/public/data/sat_trace/`

---

#### 🚁 无人机轨迹导入

| 功能 | 操作 |
|------|------|
| **手动导入** | 拖拽或点击选择 `uav_trace_*.csv` 文件，自动保存到 `public/data/uav_trace/` |
| **程序生成** | 点击「程序生成」→ 弹出参数配置窗口 → 运行 S2 模块 |

**S2 可配置参数：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 无人机数量 | 50 | 飞行无人机数 |
| 仿真时长 | 600000 ms | 10 分钟 |
| 锚点纬度/经度/海拔 | 30.0 / 104.0 / 459 | 救援中心 |
| 搜索半径 | 2500 m | 螺旋搜索范围 |
| 飞行高度 | 50 m | 相对地面高度 |
| 检测范围 | 60 m | 传感器范围 |
| 飞行速度 | 15 m/s | 巡航速度 |

> S2 输出：`S3/traces/uav_trace_{N}/` + `vis/public/data/uav_trace/`

---

#### 🔗 链路拓扑导入

| 功能 | 操作 |
|------|------|
| **手动导入** | 拖拽或点击选择 `topology_links_*.csv` 文件，自动保存到 `public/data/topology_links/` |
| **程序生成** | 下拉选择已有的卫星 + 无人机轨迹组合 → 点击「程序生成」→ 运行 S3 模块 |

S3 不需要手动填写参数——下拉框会自动扫描 `S3/traces/` 中已有的 `sat_trace_{N}` 和 `uav_trace_{N}` 目录。

> S3 输出：`S3/outputs/output_{m}_{n}/` + `vis/public/data/topology_links/`

---

#### 🌐 网络节点导入

| 功能 | 操作 |
|------|------|
| **手动导入** | 拖拽或点击选择 `networks.csv` 文件，自动保存到 `public/data/networks/` |
| **程序生成** | 下拉选择已有的 S3 输出组合 → 点击「程序生成」→ 运行 S4 模块 |

S4 的下拉框会自动扫描 `S3/outputs/` 中已有的 `output_{m}_{n}` 目录。

> S4 输出：`S4/output/output_{m}_{n}/` + `vis/public/data/networks/`

---

## 模块流水线

```
S1 (卫星轨迹) ──┐
                ├──→ S3 (链路拓扑) ──→ S4 (网络节点)
S2 (无人机轨迹)─┘
```

推荐执行顺序：

1. **S1**：生成卫星轨迹（配置卫星数量等参数）
2. **S2**：生成无人机轨迹（配置无人机数量等参数）
3. **S3**：选择上面的轨迹组合，生成链路拓扑
4. **S4**：选择 S3 的输出组合，生成网络节点数据

每次程序生成时，前端对应目录的旧文件会被自动清空，确保数据一致。
